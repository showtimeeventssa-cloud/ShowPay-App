# ShowPay v30

Complete GitHub project based on the approved ShowPay v27 visual and scroll baseline, with the button/navigation JavaScript hardened so an old or empty localStorage record cannot stop the interface from responding.

The application remains self-contained in `index.html`. Supporting project files, artwork, Supabase schema/configuration and GitHub Pages workflow are included.

Upload the contents of this folder to the root of the GitHub repository so `index.html` is directly at the repository root.

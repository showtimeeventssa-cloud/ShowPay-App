# ShowPay Artist

ShowPay Artist is a responsive progressive web app for artists and entertainers to manage clients, quotations, invoices, payments and performance schedules.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Open the published GitHub Pages address.
6. On iPhone Safari use **Share → Add to Home Screen**. On Android Chrome use **Install app / Add to Home screen**.

## Responsive design
The interface is built for iPhone, Android phones, tablets and PC, in both portrait and landscape orientations. Desktop uses a sidebar; mobile uses a compact header and bottom navigation.

## Included
- Client database with local browser storage
- Quote creation and professional quotation preview
- Quote → invoice conversion
- Invoice creation and professional invoice preview
- VAT and banking fields
- Payment status tracking
- Performance schedule/calendar
- Artist/business branding settings
- Print / Save as PDF
- PWA manifest and service worker
- ShowPay logo and artwork embedded in `index.html`

This is a front-end/local-storage version. For multi-device cloud sync, authentication and online backups, a database/backend should be added in a later version.

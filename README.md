# ShowPay v2 — Functional Navigation + Embedded Artwork

ShowPay artist quote/invoice desk. The approved ShowPay master artwork and logo are embedded directly into `index.html` as Base64 data URIs. No external artwork path is required.

## Navigation fixes
- Desktop sidebar buttons switch pages without anchor scrolling.
- Mobile bottom navigation works on iPhone/iPad widths.
- Navigation always resets the document to the top.
- More page exposes the remaining sections on mobile.
- Marketing and Contract buttons now have working forms and delete actions.

## Data
ShowPay stores local data in the browser's localStorage and supports JSON export/import.

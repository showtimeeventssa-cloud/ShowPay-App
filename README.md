# ShowPay Artist

A responsive Progressive Web App for artists to manage clients, quotes, invoices, payments and schedules.

## GitHub Pages
1. Upload the contents of this folder to a GitHub repository.
2. Enable **Settings → Pages → Deploy from branch**.
3. Open the GitHub Pages URL on iPhone, Android or PC.
4. On iPhone use **Share → Add to Home Screen**. On Android use **Install app / Add to Home screen**.

## Included
- Responsive portrait + landscape layout.
- Artist-focused ShowPay branding and concert artwork.
- Client records.
- Quote creation with line items and validity dates.
- Invoice creation with line items and due dates.
- Quote and invoice document previews.
- Quote/invoice PDF workflow through the browser's Print/Save as PDF.
- Business/VAT/banking details.
- Schedule/calendar.
- Local browser storage so the prototype works without a server/database.
- PWA manifest, service worker and home-screen icons.

## Important
This is a client-side GitHub Pages prototype. Data is stored locally in the browser. For multi-device cloud sync, user accounts, secure backups and production invoicing, connect a backend/database in the next build stage.
